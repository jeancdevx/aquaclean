# BPMN vigentes

Los siete archivos `*-v2.bpmn` especifican el pedido al detalle: Integral, P1R, P1, P2, P3, P4 y Orquestación. Son BPMN 2.0 descriptivos `isExecutable=false`; LangGraph implementa contratos y controles, no carga estos XML. Los archivos sin sufijo V2 son antecedentes corporativos V1; se conservan originales en `../antecedentes/v1/bpmn`. AS IS y RPA son referencias históricas. La validación y capturas nuevas se generan en artifacts/semana10, sin modificar los resultados históricos.
