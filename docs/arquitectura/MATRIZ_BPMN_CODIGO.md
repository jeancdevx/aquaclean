Los números de nodos/aristas se derivan del JSON final, no del BPMN ni de los 12/16 auditados. Stage tiene rutas a review/respond; execute a review/respond; supervisor a P1–P4/clarify. No se recorren todos los destinos en un único run. Excepciones de proveedor, cancelación, conflicto y presupuesto las gestiona el worker fuera de las aristas normales. Cada revisión genérica representa un control de negocio distinto según proceso/kind. El perfil demo no prueba identidad ni separación de funciones reales.

Diferencias explícitas: no se implementa seguimiento postventa 48 h; no se declara lavado/transporte/inspección/pago bancario/factura fiscal por IA. Los límites 24 h/48 h de promesa y reproceso son de laboratorio. El reintento de notificación es solo bandeja local. La importación bpmn.io prueba formato/render, no ejecución LangGraph ni notificación externa.
