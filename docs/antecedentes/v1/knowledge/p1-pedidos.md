# Pedidos corporativos — conocimiento DEMO SINTÉTICO

Documento aprobado únicamente para esta demostración; no constituye política comercial confirmada de Aqua Clean. Versión demo-1, vigencia desde 2026-01-01.

P1 requiere cliente_id, solicitante, correo, fecha_recojo exacta en America/Lima, turno manana/tarde, tipo_ropa y bolsas. Mostrar dirección del padrón si se utiliza y confirmar el conjunto antes de registrar. Límite piloto: 1–40 bolsas y fecha hasta 30 días.

Cliente comercialmente bloqueado: requiere excepción administrativa y nueva confirmación del resumen. El texto del chat no otorga permisos. La notificación demo es una bandeja local; no acredita correo enviado.
